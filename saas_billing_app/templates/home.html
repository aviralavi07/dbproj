Cloud SaaS Subscription and Billing Management System

A database project for a software company that sells monthly plans. It records clients, their subscriptions, the invoices raised for them, the payments and refunds received, cancellations, support tickets and usage. This website explains the design of the database and contains the working application that uses it.

Open the application Read the database design

The problem

A SaaS company bills every client every month, and the amount depends on the plan, the extra users or storage used, and the payments already received. When this information is kept in separate spreadsheets and emails, invoices are calculated by hand and mistakes are common. Unpaid invoices are hard to find, refunds and cancellations are not recorded properly, and nobody can see how much revenue each plan earns.

How the pieces fit

  • The pages you see are HTML templates filled in by the Flask application.
  • The application connects to the MySQL database saas_billing_db with mysql-connector-python. Every SQL statement uses parameters, so text typed into a form is never run as SQL.
  • Actions that change more than one table, such as cancelling a subscription or recording a payment, run as one transaction.
